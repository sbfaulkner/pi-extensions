# Introduce Class Annotation

**Tag:** basic · **Source:** *Refactoring: Ruby Edition*

## Motivation

Some behavior is so common and mechanical that writing it out obscures intent — hand-rolled
constructors that copy hash values to instance variables, boilerplate accessors, callback
wiring. When the behavior can be captured declaratively, define a class-level "annotation"
(a class method invoked in the class body, like `attr_reader` or Rails' `has_many`) that
generates it. The class body then *states* the design decision instead of spelling out its
implementation. Only do this for genuinely mechanical patterns — an annotation that hides
interesting logic hurts more than it helps.

**With Sorbet:** methods generated by custom annotations are invisible to the type checker
unless you write a [tapioca](https://github.com/Shopify/tapioca) DSL compiler or hand-keep
RBI files. Weigh that maintenance cost; for a small number of classes, explicit code plus
sigs is often the better trade.

## Mechanics

1. Write a class method (in the class, a superclass, or a module) that generates the
   boilerplate behavior — typically with `define_method`.
2. Declare the annotation at the top of one class body and remove the handwritten code it
   replaces.
3. Run the tests.
4. Repeat for other classes with the same pattern, extracting the annotation to a shared
   module if it's used across classes.

## Example

Before — a constructor that's pure mechanics:

```ruby
class SearchCriteria
  def initialize(hash)
    @author_id = hash[:author_id]
    @publisher_id = hash[:publisher_id]
    @isbn = hash[:isbn]
  end
end
```

After introducing a `hash_initializer` annotation:

```ruby
module CustomInitializers
  def hash_initializer(*attribute_names)
    define_method(:initialize) do |*args|
      data = args.first || {}
      attribute_names.each do |attribute_name|
        instance_variable_set(:"@#{attribute_name}", data[attribute_name])
      end
    end
  end
end

Class.send(:include, CustomInitializers)

class SearchCriteria
  hash_initializer :author_id, :publisher_id, :isbn
end
```
