# Move Eval from Runtime to Parse Time

**Tag:** basic · **Source:** *Refactoring: Ruby Edition*

## Motivation

`eval` inside a method body runs on *every call* — paying the interpretation cost each
time, and hiding what the method does from anyone reading or profiling it. If the evaluated
code is fixed per class, move the `eval` outward so it runs once at class-definition
(parse) time, generating real methods — typically via `class_eval` with a string that
defines a `def`. The per-call cost disappears and the defined methods become inspectable.
Better still, ask whether you need string eval at all — `define_method` with a block avoids
string construction entirely (at a small closure cost).

**With Sorbet:** methods generated by string eval are exactly as invisible as any other
metaprogramming — RBI/tapioca applies. Moving eval to parse time doesn't fix typability,
but it's a prerequisite for generating the RBI definitions that do.

## Mechanics

1. Find the `eval` executed inside a method body.
2. Rewrite it as a `class_eval` at class-definition scope that defines the method(s)
   outright, interpolating what was dynamic into the generated `def`.
3. Run the tests.
4. Consider replacing the string eval with `define_method` if the generated code doesn't
   need `def`-level performance or specific arity.

## Example

Before — eval on every call:

```ruby
class Person
  def self.attr_with_default(options)
    options.each_pair do |attribute, default_value|
      define_method(attribute) do
        eval "@#{attribute} ||= #{default_value}"
      end
    end
  end

  attr_with_default emails: "[]", employers: "[]"
end
```

After moving the eval to parse time:

```ruby
class Person
  def self.attr_with_default(options)
    options.each_pair do |attribute, default_value|
      class_eval "def #{attribute}
                    @#{attribute} ||= #{default_value}
                  end"
    end
  end

  attr_with_default emails: "[]", employers: "[]"
end
```

The string is now evaluated once per attribute at load, defining ordinary methods.
